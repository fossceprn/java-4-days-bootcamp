## 📅 DAY 2 – OBJECT-ORIENTED PROGRAMMING

### Question 1 – Bank Account Management

**📝 Problem Statement:**

Create a class called `BankAccount` with the following:

**Instance Variables:**

- `accountHolder`
- `accountNumber`
- `balance`

**Requirements:**

1. A constructor to initialize all three variables.
2. A method `deposit(double amount)` to add money to the balance.
3. A method `withdraw(double amount)` to withdraw money if sufficient balance is available.
4. A method `displayDetails()` to display account information.

**In the main method:**

1. Create two `BankAccount` objects with different details.
2. Deposit money into both accounts.
3. Withdraw money from one account.
4. Display the updated details of both accounts.

**Concepts Covered:** Classes, objects, constructors, methods, and instance variables.

---

### Question 2 – Animal Kingdom: Inheritance

**📝 Problem Statement:**

Create a parent class called `Animal` with the following:

- `name`
- `age`
- `eat()` method
- `sleep()` method

Create two child classes: `Dog` and `Cat`.

**Requirements:**

1. Both child classes should inherit from `Animal`.
2. Add a `bark()` method to `Dog`.
3. Add a `meow()` method to `Cat`.
4. Create objects of both child classes.
5. Display their inherited and individual behaviours.

**Concepts Covered:** Inheritance, parent class, child class, and code reusability.

---

### Question 3 – Shape Area Calculator: Abstract Class

**📝 Problem Statement:**

Create an abstract class called `Shape` containing only one abstract method:

```java
abstract double calculateArea();
```

Create three child classes:

1. **Circle** – Calculate area using π × radius × radius.
2. **Rectangle** – Calculate area using length × width.
3. **Triangle** – Calculate area using ½ × base × height.

**Requirements:**

1. Each child class must implement `calculateArea()`.
2. Create objects of all three classes.
3. Use a `Shape` reference to call `calculateArea()` for each object.
4. Display the calculated areas.

**Concepts Covered:** Abstract class, abstract method, inheritance, and runtime polymorphism.

# 🚀 Java Swing Calculator

## 📝 Project Problem Statement

Develop a calculator application using Java Swing that allows users to perform basic arithmetic operations through a graphical user interface.

## 📌 Project Description

This project is a graphical calculator developed using Java Swing in Eclipse IDE. It provides a user-friendly interface with number buttons and arithmetic operation buttons. Users can perform calculations by clicking the buttons, and the results are displayed on the screen.

## ✨ Key Features

- Addition, subtraction, multiplication and division.
- Percentage calculation.
- Positive and negative number conversion.
- Decimal number support.
- Clear (AC) functionality.
- Error handling for division by zero.
- User-friendly graphical interface.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **IDE:** Eclipse IDE
- **GUI Framework:** Java Swing
- **Concepts:** Object-Oriented Programming, Event Handling, Arrays, Loops and Conditional Statements.
